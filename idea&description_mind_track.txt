Опис ідеї для цього проєкта: 

1. Суть
Це веб-додаток, який допомагає людям не лише “вести щоденник настрою”, а аналізує патерни поведінки, думок і відчуттів — щоб бачити, як змінюється їхнє мислення, емоції й мотивація з часом.
Тобто: як Strava чи Garmin, тільки для голови, а не для ніг.
________________________________________
2. Що робить додаток
1.	Щоденні короткі записи — “як день?”, “що тебе турбувало?”, “що принесло задоволення?”. Можна вводити текстом, голосом або емоджі.
2.	AI-аналіз тексту — визначає тональність (радість, злість, страх, спокій), повторювані теми (робота, навчання, стосунки).
3.	Графіки емоцій — по днях, тижнях, місяцях. Можеш побачити, наприклад: “у тебе злість різко росте в понеділок” або “спокій підвищується після прогулянок”.
4.	Рекомендації — не психологічна порада, а проста аналітика: “ти краще себе почуваєш, коли лягаєш спати до 23:00” (якщо користувач додає час сну).
5.	AI-чат-щоденник — “розмова з собою” у безпечному середовищі: користувач може переписуватися з моделлю, яка ставить м’які запитання, допомагає сформулювати думку або розкласти емоцію на причини.
6.	Система “рефлексійних нагадувань” — раз на тиждень користувач отримує коротке повідомлення з підсумком тижня: “Ти 3 дні поспіль згадував про втому — може, час зробити перерву?”
________________________________________
3. Комерційна модель
•	Freemium:
Безкоштовна версія — базовий трекінг і графіки.
Платна — детальний AI-аналіз + PDF-звіт (“емоційний профіль місяця”), можливість зберігати голосові нотатки, інтеграції з календарем.
•	Партнерства:
Колаборації з психотерапевтами, освітніми платформами (для студентів, фрилансерів, розробників).
•	White-label:
Компанії можуть давати доступ своїм співробітникам (наприклад, у програмах wellbeing).
________________________________________
4. Чому це актуально
•	Психоемоційна втома — глобальна тема після пандемії, війни, новинної перенасиченості.
•	Люди вже користуються трекерами для фізичного здоров’я, але не мають простих інструментів, щоб бачити закономірності у власному мисленні.
•	AI-технології зараз дозволяють робити це м’яко, без “моралі” — просто через аналіз тексту, як дзеркало.
________________________________________
5. MVP (мінімальний життєздатний продукт)
1.	Форма щоденного запису (текст/емоджі/оцінка настрою).
2.	Аналітика AI (тональність, ключові слова, прості графіки).
3.	Стрічка записів + фільтри за темами.
4.	Щотижневий звіт — короткий текст із підсумками (“ти частіше згадував роботу”, “рівень спокою зріс на 15%”).
5.	Проста автентифікація (Google/Email), PWA-режим (щоб можна було “встановити” як додаток).
________________________________________
6. Потенціал
Як Pet-проєкт це виглядає “дружньо”: легко зробити гарний інтерфейс, цікаво попрацювати з LLM, зрозуміла цінність для людей.
Як комерційний — потенціал реально великий: психологічний self-care-ринок росте швидше, ніж фітнес-аплікації.

🔹 Основна ідея
Один веб-додаток, який:
1.	Відстежує внутрішній стан (емоції, думки, мотивацію) — через щоденні короткі записи, голосові нотатки, AI-аналіз тексту.
2.	Відстежує зовнішні звички уваги — коли і як ти користуєшся соцмережами, YouTube, AI-чатами.
3.	Показує зв’язок між цими двома світами:
наприклад, “у дні, коли ти проводив понад 1 годину в TikTok, твій рівень фокусу падав на 30% і ти частіше писав про втому.”
4.	Дає м’які інструменти для відновлення балансу — не заборони, а керовані “затримки”, короткі рефлексії, альтернативні дії.
________________________________________
🔹 Як це виглядає з боку користувача
•	Ранок: коротке опитання — “як спав?”, “настрій?”, “план дня”.
•	День: розширення у браузері фіксує, коли відкриваєш TikTok/YouTube, і може вставити 5-секундну “пауза-рефлексію”:
“Ти справді хочеш відволіктись, чи просто втомився?”
•	Вечір: короткий запис думок (текстом або голосом). AI-аналізує тон, теми, визначає рівень стресу.
•	Щотижневий звіт:
– “Емоційна динаміка тижня”;
– “Баланс навчання/розваг”;
– “Твої тригери відволікання”;
– “Рекомендований план на наступний тиждень” (час тиші, фокус-слоти, вправи).
________________________________________
🔹 Що в середині технічно
•	AI-аналіз настрою та контенту: класифікація тексту/мовлення (радість, втому, тривогу, спокій).
•	Імпорт або розширення для відстеження активності: через Browser API або ручні звіти (“сьогодні 45 хв TikTok”).
•	Єдина база даних — записи настрою, дії, фокус-сесії, тригери.
•	AI-модуль “Сократ”: ставить уточнюючі запитання, допомагає усвідомити, чому ти зайшов у стрічку.
•	Режим “Digital Detox Week”: тимчасове посилення обмежень + гейміфікація (бали за дні без бездумного скролу).
________________________________________
🔹 Чому це не суперечить
•	MindTrack = внутрішня діагностика.
•	Anti-scroll модуль = зовнішня гігієна.
Разом: показник балансу — наскільки твій розум відпочиває, навчається, розважається і не перевантажується.
________________________________________
🔹 Комерційна модель
•	Free: базові трекінги настрою й часу.
•	Pro (4–6 $/міс): повна аналітика, AI-звіт “емоції ↔ звички”, індивідуальні рекомендації, “детокс-режим”, експорт PDF.
•	Wellbeing for Teams: доступ для студентських або робочих груп, звіт без персональних даних (для HR чи викладачів).
________________________________________
🔹 MVP на 1 розробника (8 тижнів)
1.	Реєстрація, профіль, сторінка “Мій день”.
2.	AI-аналіз текстових нотаток.
3.	Розширення для фіксації відкриття певних сайтів.
4.	Дашборд із графіками: настрій ↔ користування соцмережами.
